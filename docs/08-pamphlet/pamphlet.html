何を決めたか

  • コマンドは大文字 2 文字、行末は CR+LF。シリアル端末で手打ちしてそのまま試せる。
  • CPU からの応答は+（成功）／-（エラー）の 1 文字で見分ける。何も付かない行は CPU 自身の通知（着手など）。
  • 必須は受信 9 種・送信 4 種だけ。BO など残りは任意で、受けても読み飛ばしてよい。FPGA の最小実装でも適合できる。

意見をください（仕様はまだ決まっていません）

  1. 合法手があるのに CPU が PA を返してきた。PC はパスとして通すか、不正応答にするか。
  2. 対局中に SB / SW が届いた。現対局を捨てて新規にするか、無視するか。
  3. 自分の手番中に PA（相手パス通知）が届いた。無視するか、-06 を返すか。

デモ机soft‑FPGA × WebAssembly

Verilog で書いたレトロ CPU を Verilator で C++ にし、WebAssembly にしてブラウザで動かします。命令エミュレータでは見えない内部信号（T‑state、バスサイクル、状態遷移）をリアルタイムに観測できるのが取り柄です。

  • 6502 / Apple‑I（wozmon → Integer BASIC）
  • 8080 / CP/M 2.2（MBASIC、BDS C、ゲーム）
  • PDP‑11 / Unix V6（MMU、ロジックアナライザ表示）

デモ机では 6502 / Apple‑I を Raspberry Pi Pico 2 の実機でも動かします（当日の状況により Wasm 版）。

部品管理QR Note

部品に貼った QR シールをスマホで読むと、その部品のノート（特性表、回路図、メモ）が開きます。部品が増えても、読み取るだけで該当ノートにたどり着けます。

  • タグ検索と特性表
  • 数式・回路図・図表の記法、シールの印刷

デモはログイン demo / demo。データは毎時 0 分にすべてリセットされます。

回路図tommie‑fence

Markdown のコードフェンスに YAML で部品と配線を書くと、回路図、ブレッドボードの実体配線図、ユニバーサル基板の配線図になります。回路図と実体配線図を同じ記法で並べて描けます。

  • 何も入れずにブラウザで試せる playground
  • VS Code 拡張（.vsix）をリリースで配布

図の流儀（信号は左から右、電位の高いほうが上、など）を Claude 用の skill 集にもしています。
