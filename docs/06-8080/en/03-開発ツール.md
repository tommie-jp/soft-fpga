# 03. Development Tools

## 1. Assembler

### z80asm (adopted)

```bash
sudo apt install z80asm
```

This is a Z80 assembler, but since the 8080 instruction set is a subset of Z80,
as long as you avoid Z80-specific instructions (JR, DJNZ, EX AF,AF', etc.)
the generated byte sequence runs perfectly on the 8080/vm80a.

```bash
z80asm --output=bios.bin bios.asm
```

Constants are defined as `name: equ 0xHHHH`; hexadecimal uses the `0x` prefix.

### pasmo (alternative)

```bash
sudo apt install pasmo
```

The `--8080` flag enables 8080-specific mnemonics (MVI, MOV, JMP, etc.),
but there is less documentation available than for z80asm.

## 3. CPU Functional Tests

### 8080EX1.COM — Ian Bartholomew

The 8080 equivalent of Klaus Dormann's 6502 functional test.
Runs under CP/M and exhaustively tests all 8080 instructions, verifying results
with CRC checksums.

| Item | Details |
|------|---------|
| Format | CP/M `.COM` file |
| Verification method | Verifies the execution result of each instruction group using CRC32 |
| Expected CRC | Hardcoded in the source |
| Download | `https://mdfs.net/Software/Z80/Exerciser/` |

```text
# Run after booting CP/M
A>8080EX1
8080 instruction exerciser
...
Tests complete
```

If all tests pass and "Tests complete" is displayed, vm80a is proven to be working correctly.

### How to Run

1. Place `8080EX1.COM` on drive A of the DSK image
2. Boot CP/M
3. Run `8080EX1`
4. Confirm that "Tests complete" is reached with no CRC mismatch errors

## 4. Disk Image Operations — cpmtools

```bash
sudo apt install cpmtools
```

`ibm-3740` is a built-in definition in cpmtools (77T×26S×128B = 256,256 B).
**No addition to diskdefs is required.**

### Creating a New Disk Image

```bash
# 1. Create a blank image
dd if=/dev/zero of=new.dsk bs=128 count=$((77*26))

# 2. Initialize the CP/M filesystem (fills the directory area with 0xE5)
mkfs.cpm -f ibm-3740 new.dsk
```

### Working with an Existing Image

```bash
# List directory
cpmls -f ibm-3740 cpm22.dsk

# Copy from host to image
cpmcp -f ibm-3740 cpm22.dsk 8080EX1.COM 0:

# Extract from image to host
cpmcp -f ibm-3740 cpm22.dsk 0:8080EX1.COM .

# Delete a file
cpmrm -f ibm-3740 cpm22.dsk 0:8080EX1.COM
```
