# 20. Cycle Counter (T-State Measurement)

A T-state (clock cycle) measurement feature exclusive to the soft-FPGA CP/M simulator.
`step()` is called once per T-state; the harness counts these internally and makes
the value readable via I/O ports.

## 1. I/O Port Specification

| Port | Direction | Operation |
|------|-----------|-----------|
| `30h` | OUT | Reset the counter (value ignored) |
| `30h` | IN  | Latch the counter and return bits 0–7 |
| `31h` | IN  | Return latched bits 8–15 |
| `32h` | IN  | Return latched bits 16–23 |
| `33h` | IN  | Return latched bits 24–31 |

`IN 30h` atomically latches the 32-bit value, so all four `IN` reads return a consistent snapshot.

The counter is a 32-bit unsigned integer.
At the equivalent 2 MHz clock rate it overflows after about 2000 seconds,
which is rarely an issue in practice.

## 2. Usage from BDS C

Header file: `sw/cpm/cycl.h`

```c
#include "cycl.h"

/* Measurement example (BDS C 1.60: no long, int only) */
int t0, t1;

cycl_reset();
t0 = cycl_read();

/* <- insert code to measure here (< 65535 T) <- */
for (i = 0; i < 500; i++)
    buf[i] = buf[i] + 1;

t1 = cycl_read();
printf("cycles: %d\n", t1 - t0);
```

### Functions

| Function | Return | Description |
|----------|--------|-------------|
| `cycl_reset()` | — | Reset counter to 0 (macro) |
| `cycl_read()` | `int` (16-bit) | Return T-state count (max 65535 T) |

**BDS C 1.60 limitation**: No `long` support — restricted to 16-bit integers (0–65535 T).
65535 T ≈ 33 ms at 2 MHz. For longer measurements, reduce N and measure in segments.

```c
/* Measure overhead */
int t0, t1;
cycl_reset();
t0 = cycl_read();
t1 = cycl_read();
/* overhead = t1 - t0  (typically ~30-40 T) */
```

## 3. Usage from Assembly

```asm
; Reset
XRA A
OUT 30H

; Latch and read (16-bit: BC = count)
IN  30H     ; latch, bits 0-7
MOV C, A
IN  31H     ; bits 8-15
MOV B, A
; BC = 16-bit T-state count
```

## 4. 8080 Key Instruction T-State Counts (Reference)

| Instruction | T-States |
|-------------|----------|
| `MOV r,r` | 5 |
| `MVI r,n` | 7 |
| `LXI rp,nn` | 10 |
| `ADD r` | 4 |
| `INR r` | 5 |
| `DCR r` | 5 |
| `JMP nn` | 10 |
| `CALL nn` | 17 |
| `RET` | 10 |
| `IN p` | 10 |
| `OUT p` | 10 |
| `LHLD nn` | 16 |
| `SHLD nn` | 16 |

## 5. Notes

- This counter is **exclusive to the soft-FPGA simulator** and does not work on real CP/M hardware.
- Operates independently of the `--ro` / `--no-save` flags.
- Calling `sim_init()` resets the counter (starts at 0 when CP/M boots).
- For very long measurements (> 2^32 T-states), beware of overflow.
