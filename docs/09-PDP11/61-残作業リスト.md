## C. 低優先度

### 8. `waited` / `iopage_access` / `mmu_on` を LA 信号に追加

harness.cpp の ring buffer Word3 に既に収録済みだが `sft-pdp11-la-defs.js` に信号定義がない。

| 信号 | Word3 ビット | 意味 |
|------|------------|------|
| `waited` | [18] | CPU バス待ちストール |
| `iopage_access` | [20] | I/O ページアクセス |
| `mmu_on` | — | MMR0[0]（MMU 有効化タイミング、要 obs 追加） |

- 変更: `js/sft-pdp11-la-defs.js`

### 9. MMU D-space パネル

現在は Kernel / User I-space PAR/PDR のみ表示。
D-space 追加は harness.cpp の `sim_get_mmu_snap()` 拡張で対応可能。

- 変更: `examples/09-pdp11/cxx/harness.cpp`（PDR 読み取り拡張）
- 変更: `examples/09-pdp11/web/index.html`（D-space タブ追加）
