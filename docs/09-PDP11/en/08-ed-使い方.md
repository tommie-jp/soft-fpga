# 11. ed — Line-Oriented Text Editor Usage <a class="qr-link" href="../../../docs/09-PDP11/img/08-en-QR.png">QR</a>

The standard text editor in Unix V6. Edits files line by line without using a screen.
Commands are entered as a single character and executed by pressing Enter.

---

## 1. Starting and Quitting

```text
# ed               ← start with a new buffer
# ed hello.c       ← load an existing file (byte count is displayed)
```

After startup, the **`*`** prompt appears and the editor waits for command input.

| Action | Command | Description |
|--------|---------|-------------|
| Save and quit | `w` → `q` | Run as separate commands |
| Quit without saving | `q` | Warning if unsaved; press `q` again to force quit |
| Save | `w` | Overwrite-save to the current filename |
| Save as | `w newfile` | Save to a different file (current filename does not change) |

---

## 2. Line Addresses

Every ed command uses an address to specify which line(s) to operate on.

| Address | Meaning |
|---------|---------|
| (omitted) | Current line (`.`) |
| `.` | Current line |
| `$` | Last line |
| `n` | Line n (1-based) |
| `.+n` / `+n` | n lines after the current line |
| `.-n` / `-n` | n lines before the current line |
| `1,$` | All lines (first to last) |
| `%` | Shorthand for `1,$` (may not be supported in all ed versions) |
| `/pattern/` | First line matching `pattern` searching forward from the current line |
| `?pattern?` | First line matching `pattern` searching backward from the current line |

Two addresses joined with `,` form a range.

```text
1,5p    ← display lines 1–5
3,$d    ← delete from line 3 to the end
.,.+2p  ← display the current line and the next 2 lines
```

---

## 3. Command Reference

### 3.1 Display

| Command | Description |
|---------|-------------|
| `p` | Display the current line |
| `1,$p` | Display all lines |
| `=` | Display the current line number |
| `$=` | Display the total number of lines |
| `n` | Display the current line with its line number (numbered version of `p`) |
| `1,$n` | Display all lines with line numbers |
| `l` | Display the line showing control characters explicitly as `\n` / `\t` |

### 3.2 Input

Both commands accept text input and end input mode when a **line containing only `.` (dot line)** is entered.

| Command | Description |
|---------|-------------|
| `a` | Append lines **after** the current line |
| `i` | Insert lines **before** the current line |
| `c` | **Replace** the current line with new text (change) |

```text
* a
main() {
    printf("Hello, V6!\n");
}
.
```

Text mode continues until a line containing only `.` is entered.

### 3.3 Delete, Move, and Copy

| Command | Description |
|---------|-------------|
| `d` | Delete the current line |
| `1,3d` | Delete lines 1–3 |
| `3m5` | Move line 3 to after line 5 |
| `1,3m$` | Move lines 1–3 to the end |
| `3t5` | Copy line 3 to after line 5 (transfer/copy) |
| `1,3t$` | Copy lines 1–3 to the end |

### 3.4 File Operations

| Command | Description |
|---------|-------------|
| `w` | Save to the current file (displays byte count) |
| `w file` | Save to `file` |
| `r file` | Read the contents of `file` and insert after the current line |
| `e file` | Discard the buffer and load `file` |
| `f` | Display the current filename |
| `f file` | Change the current filename |

### 3.5 Search

| Command | Description |
|---------|-------------|
| `/pattern/` | Forward search (press Enter alone to repeat) |
| `?pattern?` | Backward search |
| `g/pattern/p` | Display all lines matching `pattern` |
| `g/pattern/d` | Delete all lines matching `pattern` |

---

## 4. Substitution Command `s`

```text
[addr]s/old/new/[flags]
```

| Form | Description |
|------|-------------|
| `s/old/new/` | Replace the first occurrence of `old` with `new` on the current line |
| `s/old/new/g` | Replace all occurrences of `old` with `new` on the current line |
| `1,$s/old/new/g` | Replace all occurrences of `old` with `new` on every line |
| `s/old//` | Delete `old` (replace with empty string) |
| `s/old/new/p` | Replace and display the resulting line |

### Common Regular Expression Symbols

| Symbol | Meaning |
|--------|---------|
| `.` | Any single character |
| `*` | Zero or more repetitions of the preceding character |
| `^` | Beginning of line |
| `$` | End of line |
| `[abc]` | Any one of a, b, or c |
| `[^abc]` | Any character other than a, b, or c |
| `\(` `\)` | Grouping (back-reference with `\1`) |

## 5. Typical Usage Examples

### 5.1 Create and Save a New File

```text
# ed
* a
main() {
    printf("Hello, World!\n");
}
.
* w hello.c
38
* q
```

- The `a` command starts text input.
- `.` ends input mode.
- `w hello.c` saves the file (38 bytes displayed).

### 5.2 Open an Existing File and Rewrite One Line

```text
# ed hello.c
38
* 1,$n
1       main() {
2           printf("Hello, World!\n");
3       }
* 2s/World/V6/
* 1,$p
main() {
    printf("Hello, V6!\n");
}
* w
37
* q
```

### 5.3 Display All Lines and Then Delete a Specific Line

```text
* 1,$n          ← view all lines with line numbers
* 3d            ← delete line 3
* 1,$p          ← verify
* w
```

### 5.4 Append a Line (at the End)

```text
* $a
int x = 42;
.
* w
```

### 5.5 Delete All Lines Matching a Pattern

```text
* g/debug/d     ← delete all lines containing "debug"
* w
```

### 5.6 Replace a String Across All Lines at Once

```text
* 1,$s/printf/fprintf/g
* w
```

## 6. Writing hello.c with ed and Compiling with cc (Demo Procedure)

```text
# ed
* a
main() {
    printf("Hello, Unix V6!\n");
}
.
* w hello.c
35
* q
# cc hello.c
# ./a.out
Hello, Unix V6!
#
```

Key points:

- Watch the spelling of `main()` (a typo such as `miin` causes a Bus error).
- Do not forget the opening `{`.
- Get into the habit of verifying the contents with `1,$p` before saving with `w`.

## 7. Common Mistakes and Remedies

| Symptom | Cause | Remedy |
|---------|-------|--------|
| `?` is displayed | Invalid command or pattern not found | Check the command and address. No match found for `/pattern/` |
| `q` does not exit | There are unsaved changes (ed warns) | Run `w` then `q`, or press `q` a second time |
| The dot line `.` has no effect | `.` was typed at a position other than the start of the line | Type `.` + Enter at the very beginning of the line (no other characters) |
| A line disappeared | `d` was executed by mistake | The `u` command can undo the most recent change once (V6 ed may not support this) |
| Saved to the wrong file | `w` was pressed without specifying a name | Check the current filename with `f`, then run `w` |
