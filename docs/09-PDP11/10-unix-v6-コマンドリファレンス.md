# 10. Unix V6 コマンドリファレンス <a class="qr-link" href="docs/10-unix-v6-コマンドリファレンス-QR.png">QR</a>

このシミュレータに収録されている Unix V6（1975）の主要コマンド一覧。
コマンドの多くは `/bin/` または `/usr/bin/`（ゲームは `/usr/games/`）に存在する。
掲載コマンドは実際の V6 ファイルシステム（`/bin`・`/usr/bin`・`/usr/games`）の
中身と照合済みで、V6 に存在するものだけを載せている。

## 1. シェル組み込み

Thompson シェル (`/bin/sh`) の組み込みコマンド。

| コマンド | 書式 | 説明 |
|---------|------|------|
| `chdir` | `chdir dir` | カレントディレクトリを変更（V6 の組み込み）|
| `exit` | `exit` | シェル終了（ログアウト） |
| `wait` | `wait` | 子プロセスの終了を待つ |

## 2. ファイル操作

| コマンド | 説明 | 使用例 |
|---------|------|--------|
| `ls` | ファイル一覧。`-l` で詳細、`-a` で隠しファイルも表示 | `ls -l /usr` |
| `cat` | ファイル内容をコンソールに出力 | `cat /etc/passwd` |
| `cp` | ファイルコピー | `cp src dst` |
| `mv` | ファイル移動・改名 | `mv old new` |
| `rm` | ファイル削除。`-r` でディレクトリ再帰削除 | `rm file` |
| `mkdir` | ディレクトリ作成 | `mkdir /tmp/work` |
| `rmdir` | 空ディレクトリ削除 | `rmdir /tmp/work` |
| `ln` | ハードリンク作成（V6 にシンボリックリンクはない）| `ln src lnk` |
| `chmod` | パーミッション変更（8 進数指定）| `chmod 755 prog` |
| `chown` | 所有者変更 | `chown root file` |

## 3. テキスト処理

| コマンド | 説明 | 使用例 |
|---------|------|--------|
| `ed` | 行指向テキストエディタ（V6 標準）| `ed file.txt` |
| `grep` | 正規表現検索。`-v` で反転 | `grep root /etc/passwd` |
| `sort` | 行を辞書順ソート | `sort /etc/passwd` |
| `wc` | 行数・単語数・バイト数カウント | `wc /usr/sys/ken/main.c` |
| `diff` | 2 ファイルの差分 | `diff a.c b.c` |
| `pr` | ページ番号付きで整形出力 | `pr file.txt` |

|---------|------|--------|

| `ps` | プロセス一覧。`-ag` で全プロセス | `ps -ag` |

## 5. 開発ツール

| コマンド | 説明 | 使用例 |
|---------|------|--------|
| `cc` | C コンパイラ（Dennis Ritchie 版） | `cc hello.c` |
| `as` | PDP-11 アセンブラ | `as prog.s` |
| `ld` | リンカ | `ld /lib/crt0.o prog.o -lc` |
| `ar` | アーカイブ管理（ライブラリ作成）| `ar tv /lib/libc.a` |
| `nm` | シンボルテーブル表示 | `nm a.out` |
| `od` | バイナリを 8 進ダンプ | `od -c a.out` |
| `db` | 静的デバッガ（逆アセンブル・コアダンプ解析）→ [14 章](14-db-デバッガー-使い方.md) | `db a.out` |
| `cdb` | C 言語用デバッガ | `cdb a.out` |

### cc の基本的な使い方

```text
# コンパイルのみ
cc -c hello.c       ← hello.o を生成

# コンパイル＋リンク（標準）
cc hello.c          ← a.out を生成

# 実行
./a.out
```

## 6. 電卓・計算

### dc — 逆ポーランド電卓

Thompson が書いた `dc` は Unix V6 を代表するユーティリティ。

```text
dc
  2 3 + p       ← 5
  10 k          ← 小数精度を 10 桁に設定
  355 113 / p   ← 3.1415929203 (π 近似)
  q             ← 終了
```

| コマンド | 説明 |
|---------|------|
| `p` | スタックトップを表示 |
| `q` | 終了 |
| `+` `-` `*` `/` | 四則演算（スタック上位 2 つを演算）|
| `nk` | 小数精度を n 桁に設定 |
| `v` | 平方根 |
| `^` | べき乗 |

### bc — 高水準計算機（dc のフロントエンド）

```text
bc
  scale=5
  sqrt(2)     ← 1.41421
  ^D          ← EOF で終了
```

## 8. ed — 行指向テキストエディタ

V6 標準の `ed` は行バッファを介してファイルを編集する。

### 起動

```text
# root@unix # ed
a
Hello, Unix V6!
.
p
q
```

### 主なコマンド

| コマンド | 説明 |
|---------|------|
| `a` | 現在行の後ろに追加モード（`.` のみの行で終了）|
| `i` | 現在行の前に挿入モード（`.` のみの行で終了）|
| `p` | 現在行を表示 |
| `l` | 制御文字を見せながら表示 |
| `d` | 現在行を削除 |
| `s/old/new/` | 現在行の最初の `old` を `new` に置換。`g` で全置換 |
| `w file` | ファイルに保存 |
| `q` | 終了（未保存でも `q` を 2 回で強制終了）|
| `1,$p` | 全行表示 |
| `/pattern/` | 正規表現で前方検索 |

## 9. TTY 設定（stty）

### TTY 特殊文字一覧

Unix V6 TTY ドライバが cooked モード（デフォルト）で解釈する特殊文字。

| 文字 | コード | 名称 | 変更 | 説明 |
|------|--------|------|------|------|
| `@` | 0x40 | kill-line | `stty kill X` | 入力中の行全体を破棄 |
| DEL | 0x7F | erase | `stty erase X` | 直前の 1 文字を削除 |
| `^D` | 0x04 | CEOT (EOF) | 不可 | `read()` を 0 返却（EOF）|
| `^C` | 0x03 | CINTR | 不可 | フォアグラウンドプロセスに SIGINT |
| `^\` | 0x1C | CQUIT | 不可 | SIGQUIT + コアダンプ |

`kill` と `erase` の 2 つだけが `stty` で変更できる。残り 3 つはカーネルにハードコードされている。

### stty 使用例

```text
stty               ← 現在の TTY 設定を表示
stty kill @        ← kill-line を @ に戻す（デフォルト）
stty erase ^?      ← erase を DEL（0x7F）に戻す
```

kill/erase を一時的に無効化する場合は、未使用の制御文字（例: `^A` = 0x01）を設定する。

### EDITOR ボタンによるファイル転送

このシミュレータの EDITOR ボタンは、**TTY を完全にバイパス**して V6 FS ディスクイメージに
直接書き込む方式を採用している。`@` kill-line や erase 文字による garbling の問題を回避できる。

ファイルは `/tmp/<ファイル名>` に書き込まれる。書き込み完了後に端末へ確認メッセージが表示される。

#### 利用例

```text
# EDITOR で loop.s を書いて送信 → /tmp/loop.s に書き込まれる
# 端末に "[Editor] /tmp/loop.s を書き込みました" と表示
# その後 as を実行
as /tmp/loop.s
a.out
```

#### 技術的制限

- 最大ファイルサイズ: 4KB（8 ブロック）
- 書き込み先は `/tmp/` のみ
- ファイル名: ASCII 印字可能文字のみ、14 文字以下
- 同名ファイルは上書き

## 10. このシミュレータ固有の動作

| 項目 | 内容 |
|------|------|
| ブート | `rkunix` を入力して Unix V6 カーネルを起動 |
| ログイン | `login: root`（パスワードなし）|
| シェル | `/bin/sh`（Thompson シェル）|
| プロンプト | `#`（root シェル）|
| Ctrl+\\ | シミュレーション終了（ブラウザ版では Pause ボタン）|
| Ctrl+C | Unix 側に SIGINT を送る（コマンド中断）|
