# 13. Unix V6 C コンパイル入門

> **注意（WASM 版）**: ブラウザ上の WASM シミュレーターでは `cc` は現在動作しません。
> MMU メモリ検出バグのため `maxmem` が実際より小さく設定されます。
> SIMH や Linux ネイティブ版では正常動作します。詳細は [41-cc-コンパイル-バグ調査.md](41-cc-コンパイル-バグ調査.md) を参照。

Unix V6 に搭載されているのは Dennis Ritchie が書いたオリジナルの C コンパイラ（1975年頃）。
ANSI C（1989年）より 14 年前の仕様であり、現代の C とは書き方が異なる点がある。

## 1. Hello, World

### 1.1 ソースファイルの作成

`ed` を使うか、`cat >` でリダイレクト入力する。

```text
# cat > hello.c
main()
{
    printf("Hello, World!\n");
}
```

最後に **Ctrl-D**（EOF）を入力してファイルを閉じる。

> Unix V6 C の注意点
>
> - `#include <stdio.h>` は不要（`printf` は暗黙的に使える）
> - `main()` の戻り値型 `int` は省略可能
> - 文末の `return` も省略可能

### 1.2 コンパイル

```text
# cc hello.c
```

エラーがなければ `a.out` が生成される。

### 1.3 実行

```text
# ./a.out
Hello, World!
```

## 2. コマンドライン引数を受け取る

K&R 方式（ANSI 以前）の関数引数宣言を使う。

```text
# cat > greet.c
main(argc, argv)
int argc;
char **argv;
{
    int i;
    if (argc < 2) {
        printf("usage: greet <name>\n");
        exit(1);
    }
    for (i = 1; i < argc; i++)
        printf("Hello, %s!\n", argv[i]);
}
```

```text
# cc greet.c
# ./a.out Unix V6
Hello, Unix!
Hello, V6!
```

## 4. コンパイラの内部動作

`cc` は以下のパスを順に呼び出すドライバーである。
コンパイル中に MMU PAR/PDR と GPR が激しく変化するため、
Logic Analyzer ビューとの組み合わせがデモのクライマックスに最適。

```text
/lib/c0   — フロントエンド（字句解析・構文解析）
/lib/c1   — コード生成（PDP-11 アセンブリ出力）
/lib/c2   — ピープホール最適化
/bin/as   — アセンブラ（.s → .o）
/bin/ld   — リンカ（.o + /lib/libc.a → a.out）
```

中間ファイルを確認したい場合:

```text
# cc -S hello.c       # アセンブリを hello.s として残す
# cat hello.s
```

## 5. よくある V6 C の落とし穴

| 現象 | 原因 | 対処 |
|------|------|------|
| `int` がデフォルト型 | 戻り値・変数の型省略可 | 意図的。警告も出ない |
| `void` が使えない | V6 C に `void` 型はない | 戻り値なし関数も `int` と書くか省略 |
| 配列範囲チェックなし | C の仕様通り | 手動で境界確認が必要 |
| `//` コメント不可 | `/* */` のみ有効 | ANSI C 以前の仕様 |
| `%d` に `long` を渡すと化ける | `printf` は型情報を持たない | `long` には `%ld` を使う（V6 では `%D`） |

## 6. 参考: /usr/include の主なヘッダ

```text
# ls /usr/include
```

| ヘッダ | 内容 |
|--------|------|
| `stdio.h` | `FILE`・`EOF` などの定数（`printf` 自体は不要） |
| `ctype.h` | 文字分類（`isdigit`・`isupper` 等） |
| `signal.h` | シグナル番号定数 |
| `sys/types.h` | `dev_t`・`ino_t` などカーネル型 |
