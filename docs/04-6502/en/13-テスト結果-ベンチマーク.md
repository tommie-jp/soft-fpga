# 13. Test Results and Benchmark Records

Results from Verilator host simulation (inside a Docker container).
Baseline for comparison against WebAssembly / Pico 2 execution.

Execution date: 2026-05-13
Execution environment: WSL2 (Linux 6.6.87.2-microsoft-standard-WSL2)
Command: `./doTestAll.sh`

## Host CPU Specs

| Item | Value |
| --- | --- |
| CPU | Intel Core Ultra 9 285K |
| TSC measured frequency | **3.686 GHz** (TSC delta 3,686,826,852 / 1.000 s) |
| BogoMIPS | 7372.80 (Linux kernel busy-wait calibration value ≈ TSC frequency × 2) |
| Core count | 24 cores (SMT disabled) |

> **BogoMIPS cannot be used for comparison with WebAssembly / Pico 2.**
> BogoMIPS measures the host CPU's busy-wait loop speed and is unrelated to
> Verilator simulation throughput. The only meaningful comparison metric is
> "simulated 6502 clock cycles ÷ wall-clock time", i.e., **effective simulation MHz**.

## Verilator Effective Simulation Speed (from Dormann Test)

| Environment | Measured value |
| --- | --- |
| Verilator on WSL2 (Core Ultra 9 285K) | **≈ 13.7 MHz equivalent** |
| Real Apple-1 clock | 1.023 MHz |
| Ratio (Verilator / real hardware) | ≈ 13× faster |
| Host CPU clock ratio | ≈ 1/270 (1/270th of 3.686 GHz) |

When simulation speeds for WebAssembly and Pico 2 become available, they will be added here.
