# 11. ed — 行指向テキストエディタ 使い方 <a class="qr-link" href="../../../docs/09-PDP11/08-QR.png">QR</a>

Unix V6 標準のテキストエディタ。画面を使わず行単位でファイルを編集する。
コマンドを 1 文字で入力し、Enter で実行する形式。

---

## 1. 起動と終了

```text
# ed               ← 新規バッファで起動
# ed hello.c       ← 既存ファイルを読み込んで起動（バイト数が表示される）
```

起動後は **`*`** プロンプトが現れ、コマンド入力待ちになる。

| 操作 | コマンド | 説明 |
|------|---------|------|
| 保存して終了 | `w` → `q` | 別々に実行する |
| 保存せず終了 | `q` | 未保存なら警告。もう一度 `q` で強制終了 |
| 保存 | `w` | 元のファイル名に上書き保存 |
| 別名で保存 | `w newfile` | 別ファイルに保存（カレントファイルは変わらない）|

---

## 2. 行アドレス

ed のすべてのコマンドはアドレスで操作対象の行を指定する。

| アドレス | 意味 |
|---------|------|
| (省略) | 現在行（`.`）|
| `.` | 現在行 |
| `$` | 最終行 |
| `n` | n 行目（1 から始まる）|
| `.+n` / `+n` | 現在行の n 行後 |
| `.-n` / `-n` | 現在行の n 行前 |
| `1,$` | 全行（1 行目から最終行）|
| `%` | `1,$` の短縮形（ed によっては未対応）|
| `/pattern/` | 現在行の次から `pattern` に最初に一致する行 |
| `?pattern?` | 現在行の前から `pattern` に最初に一致する行（後方検索）|

アドレスは `,` で 2 つ組み合わせて範囲を作る。

```text
1,5p    ← 1〜5 行目を表示
3,$d    ← 3 行目から末尾まで削除
.,.+2p  ← 現在行と次の 2 行を表示
```

---

## 3. 主要コマンド一覧

### 3.1 表示

| コマンド | 説明 |
|---------|------|
| `p` | 現在行を表示 |
| `1,$p` | 全行を表示 |
| `=` | 現在行番号を表示 |
| `$=` | 総行数を表示 |
| `n` | 行番号付きで現在行を表示（`p` の番号付き版）|
| `1,$n` | 行番号付きで全行を表示 |
| `l` | 制御文字を `\n` / `\t` 形式で明示して表示 |

### 3.2 入力

どちらもテキストを入力し、**`.` のみの行（ドット行）** で入力モードを終了する。

| コマンド | 説明 |
|---------|------|
| `a` | 現在行の **後ろ** に行を追加（append）|
| `i` | 現在行の **前** に行を挿入（insert）|
| `c` | 現在行を新しいテキストで **置き換え**（change）|

```text
* a
main() {
    printf("Hello, V6!\n");
}
.
```

`.` のみの行を入力するまでテキストモードが続く。

### 3.3 削除・移動・コピー

| コマンド | 説明 |
|---------|------|
| `d` | 現在行を削除 |
| `1,3d` | 1〜3 行目を削除 |
| `3m5` | 3 行目を 5 行目の後ろに移動 |
| `1,3m$` | 1〜3 行目を末尾に移動 |
| `3t5` | 3 行目を 5 行目の後ろにコピー（transfer/copy）|
| `1,3t$` | 1〜3 行目を末尾にコピー |

### 3.4 ファイル操作

| コマンド | 説明 |
|---------|------|
| `w` | カレントファイルに保存（バイト数を表示）|
| `w file` | `file` に保存 |
| `r file` | `file` の内容を現在行の後ろに読み込む |
| `e file` | バッファを破棄して `file` を読み込む |
| `f` | カレントファイル名を表示 |
| `f file` | カレントファイル名を変更 |

### 3.5 検索

| コマンド | 説明 |
|---------|------|
| `/pattern/` | 前方検索（Enter のみで繰り返し）|
| `?pattern?` | 後方検索 |
| `g/pattern/p` | `pattern` に一致する全行を表示 |
| `g/pattern/d` | `pattern` に一致する全行を削除 |

## 4. 置換コマンド `s`

```text
[addr]s/old/new/[flags]
```

| 形式 | 説明 |
|------|------|
| `s/old/new/` | 現在行の最初の `old` を `new` に置換 |
| `s/old/new/g` | 現在行の `old` をすべて置換 |
| `1,$s/old/new/g` | 全行の `old` をすべて置換 |
| `s/old//` | `old` を削除（空文字列に置換）|
| `s/old/new/p` | 置換後に行を表示 |

### 正規表現の主な記号

| 記号 | 意味 |
|------|------|
| `.` | 任意の 1 文字 |
| `*` | 直前の文字の 0 回以上の繰り返し |
| `^` | 行頭 |
| `$` | 行末 |
| `[abc]` | a / b / c のいずれか 1 文字 |
| `[^abc]` | a / b / c 以外の 1 文字 |
| `\(` `\)` | グループ化（`\1` で後方参照）|

## 5. 典型的な操作例

### 5.1 新規ファイルを作成して保存する

```text
# ed
* a
main() {
    printf("Hello, World!\n");
}
.
* w hello.c
38
* q
```

- `a` コマンドでテキスト入力開始
- `.` で入力終了
- `w hello.c` で保存（38 バイトと表示）

### 5.2 既存ファイルを開いて 1 行書き換える

```text
# ed hello.c
38
* 1,$n
1       main() {
2           printf("Hello, World!\n");
3       }
* 2s/World/V6/
* 1,$p
main() {
    printf("Hello, V6!\n");
}
* w
37
* q
```

### 5.3 全行を表示してから特定行を削除する

```text
* 1,$n          ← 行番号付きで全行確認
* 3d            ← 3 行目を削除
* 1,$p          ← 確認
* w
```

### 5.4 行を追加する（末尾に）

```text
* $a
int x = 42;
.
* w
```

### 5.5 パターン一致行をすべて削除する

```text
* g/debug/d     ← "debug" を含む行をすべて削除
* w
```

### 5.6 全行の特定文字列を一括置換する

```text
* 1,$s/printf/fprintf/g
* w
```

## 6. hello.c を ed で書いて cc でコンパイルする（デモ手順）

```text
# ed
* a
main() {
    printf("Hello, Unix V6!\n");
}
.
* w hello.c
35
* q
# cc hello.c
# ./a.out
Hello, Unix V6!
#
```

ポイント:

- `main()` のスペルに注意（`miin` など誤記すると Bus error になる）
- `{` の付け忘れに注意
- 保存前に `1,$p` で内容を確認してから `w` する習慣をつける

## 7. よくあるミスと対処

| 症状 | 原因 | 対処 |
|------|------|------|
| `?` と表示される | 無効なコマンドまたはパターン不一致 | コマンド・アドレスを確認。`/pattern/` でヒットなし |
| `q` を押しても終了しない | 未保存の変更あり（ed が警告） | `w` してから `q`、または `q` をもう一度 |
| ドット行 `.` が効かない | テキストモード中に行頭以外に `.` を打った | 行頭（他の文字なし）で `.` + Enter |
| 行が消えた | `d` を誤実行 | `u` コマンドで直前の変更を 1 回だけ取り消せる（V6 の ed は対応しない場合あり）|
| 保存先が違う | `w` だけ押したが名前を指定していない | `f` でカレントファイル名を確認してから `w` |
