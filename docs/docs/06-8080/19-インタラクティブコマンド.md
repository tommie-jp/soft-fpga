# 19. インタラクティブコマンド

CP/M シミュレータ (`cpm`) の対話モードで使えるキー操作と `!` コマンド。

## 1. 特殊キー

| キー | 動作 |
|------|------|
| `Ctrl+\` | シミュレータ終了（ダーティドライブを自動保存） |
| `Ctrl+T` | ステータス表示（PC・ドライブ状態） |
| `↑` / `↓` | コマンドヒストリ（前後のエントリへ移動） |

### `Ctrl+T` 表示例

```text
--- [Ctrl+T] status ---
CPU   PC=F234  [BIOS]
Disk  drive=B  trk=12  sec=5  dma=0080
      A: cpm22.dsk          [dirty]
      B: bdsc.dsk
      C: (blank)
      D: (blank)
```

PC 領域の分類:

| 範囲 | 表示 |
|------|------|
| `0x0000–0x00FF` | `page0` |
| `0x0100–0xDBFF` | `TPA` |
| `0xDC00–0xE3FF` | `CCP` |
| `0xE400–0xF1FF` | `BDOS` |
| `0xF200–0xFFFF` | `BIOS` |

## 2. コマンドヒストリ

CP/M の `A>` プロンプトで ↑/↓ キーを押すと、入力したコマンドの履歴を呼び出せる。

| キー | 動作 |
|------|------|
| `↑` | 1 つ古いエントリを表示 |
| `↓` | 1 つ新しいエントリを表示。最新まで戻ると↑を押した時点の入力に戻る |

### 2.1 動作の詳細

- 現在の入力をバックスペースで消去してから履歴エントリを表示する。
- 履歴エントリを表示した状態で文字を打てばそのまま編集できる。
- `Enter` を押した行をヒストリに追加する（空行・直前と同じ内容は除外）。
- 最大 100 件保持。上限超過時は古いエントリから削除される。

### 2.2 実装上の注意

ホスト側 (`main_linux.cpp`) で ESC シーケンス (`ESC [ A` / `ESC [ B`) を横取りして
バックスペースと新エントリを `send_key()` で CP/M に送り込む。
CP/M 自体はヒストリを知らず、CCP のラインバッファ経由で自然に動作する。

## 3. `!` コマンド

行頭で `!` を入力するとコマンドモードに入る。`Enter` で実行。

### 3.1 シェルエスケープ

```text
!ls
!pwd
!cp foo.com ~/backup/
```

シェルコマンドをそのまま実行し、出力をターミナルに表示する。

### 3.2 `!cap` — 出力キャプチャ

```text
!cap output.txt      # キャプチャ開始
!cap off             # キャプチャ停止
!cap                 # キャプチャ停止（引数なし）
```

CP/M のコンソール出力をファイルに保存する。実行中はリアルタイムで書き込まれる。

**用途**: CPU エクササイザの結果保存、DIR 一覧の記録など。

### 3.3 `!paste` — テキスト流し込み

```text
!paste program.bas
!paste commands.txt
```

テキストファイルの内容をキーボード入力として CP/M に流し込む。
`\n` は自動的に `\r` に変換される。

**用途**: MBASIC プログラムの入力、繰り返しコマンド列の自動実行。

**注意**: 最大 65,535 バイト。CP/M の入力バッファを圧迫しないよう 16 バイト/ループずつ送信する。

### 3.4 `!mount` — ディスク交換

```text
!mount A: /path/to/new.dsk
!mount B: work.dsk
```

実行中の CP/M を再起動せずにドライブのディスクイメージを差し替える。
差し替え後のパスは終了時の自動保存先にも反映される。

**用途**: 作業ディスクの切り替え、別プロジェクトのディスクをマウント。

## 4. Web UI コマンド（ブラウザ版専用）

ブラウザ版 (`index.html`) のターミナル入力欄で使えるコマンド。
行頭に `!` を付けて Enter を押すと UI レイヤーが横取りし、CP/M 本体や BIOS には届かない。
Linux CLI 版の `!` シェルエスケープとは別物で、コマンドセットが異なる。

### 4.1 `!ls` / `!dir` — ファイル一覧

```text
!ls
!dir
```

WASM 仮想ファイルシステム上のファイルと日時を一覧表示する。

### 4.2 `!script` / `!run` — マクロ実行

```text
!script FILENAME
!run FILENAME
```

WASM FS 上のファイルを読み込み、1 文字ずつ CONIN バッファに注入して
CP/M コマンドを自動実行する。

- 実行中はターミナル右上に `▶ macro: FILENAME` と停止ボタン `■` が表示される
- `sim_con_in_space()` でバッファ空きを確認しながら最大 64 バイト/フレームずつ送信
- 行末変換: `\r\n` → `\r`、単独 `\n` → `\r`（CP/M の改行は CR のみ）
- `^Z`（0x1A, CP/M EOF マーカー）は除去してから注入する
- マクロ先頭の `\r` がコマンド実行を担うため、`!script` 入力自体の CR は CP/M に送らない

**用途**: SUB ファイルの自動実行、繰り返しコマンド列のテスト。

#### マクロファイル内で使えるディレクティブ

マクロファイル（`.MAC` など）に以下の行を書くと、注入を制御できる。

##### `!sleep N` — 固定時間待機

```text
!sleep 200
```

N ミリ秒間、文字注入を一時停止してから次の行に進む。
画面描画の確認や CP/M 側の処理待ちに使う。

##### `!expect STR [N]` — 出力待機

```text
!expect -
!expect - 300
!expect \r- 500
```

`STR` が CONOUT に出現するまで文字注入を停止する。
`STR` が現れなかった場合は **N ミリ秒**（省略時 200ms）でタイムアウトして次の行に進む。
タイムアウト時はターミナルに黄色の警告 `[warn] !expect timeout: "-"` を表示する。

- `STR` はスペースを含まない文字列
- `\r`、`\n` はエスケープシーケンスとして解釈（`\n-` → LF + ハイフン）
- DDT のプロンプト待ちは **`!expect -` ではなく `!expect \n-` を使う**（後述）

**`!sleep` との使い分け**:

| | `!sleep N` | `!expect STR` |
|---|---|---|
| 待ち方 | 固定時間 | 実際の出力を確認 |
| 誤検知 | なし | パターン次第 |
| 過剰待機 | 常にあり | なし |
| 推奨用途 | 描画待ち・最終保険 | プロンプト確認 |

**DDT プロンプト待ちに `!expect -` ではなく `!expect \n-` を使う理由**:

DDT の D コマンド（メモリ dump）は各バイトを ASCII 表示する。
バイト値 `0x2D`（`-`）がメモリに存在すると dump 出力の ASCII 列に `-` が出現し、
`!expect -` がプロンプトと誤検知して G コマンドを早期注入してしまう。

DDT の実際のプロンプトは必ず行頭に来るため `\n-`（LF + ハイフン）でマッチする：

```text
DDT 出力の \r\n-  →  \n- を含む  →  マッチ ✅
dump 行中の 0x2D →  空白に囲まれ \n- を含まない  →  スキップ ✅
```

タイムアウトについての注意：

- DDT.COM のロード（ディスク I/O + メモリ展開）は 200ms を超えることがある
  → DDT 起動直後の `!expect \n-` には `2000`（2秒）以上を指定する
- D コマンド（dump）の出力完了を待つ場合も `500` 程度を推奨

**DDT.MAC の正しい記述例**:

```text
DDT
!expect \n- 2000
S0300
3E
FF
76
.
!expect \n- 1000
D0300,0310
!expect \n- 500
G300
```

### 4.3 `!type` / `!cat` — ファイル内容表示

```text
!type FILENAME
!cat FILENAME
```

WASM FS 上のファイル内容をターミナルに表示する。
`\n` → `\r\n` 変換を行うのでテキストファイルを読みやすく表示できる。

### 4.4 `!upload` / `!ul` — ホストからアップロード

```text
!upload
!ul
```

ブラウザのファイル選択ダイアログを開き、選択したファイルを WASM FS に保存する。

**用途**: ホストで作成した `.COM` ファイルや SUB ファイルをブラウザ内 CP/M に転送する。

### 4.5 `!get` / `!dl` — WASM FS からダウンロード

```text
!get FILENAME
!dl FILENAME
```

WASM FS 上のファイルをホスト PC にダウンロード（ブラウザの保存ダイアログ）する。

### 4.6 `!rm` / `!del` — ファイル削除

```text
!rm FILENAME
!del FILENAME
```

WASM FS 上のファイルを削除する。

### 4.7 `!stop` — マクロ停止

```text
!stop
```

実行中の `!script` / `!run` を即座に中断する。
注入待ち文字列をすべて破棄し、マクロステータス表示を消去する。
ターミナル右上の `■` ボタンをクリックしても同じ処理が実行される。

### 4.8 `!help` — コマンド一覧

```text
!help
!?
```

利用可能な `!` コマンドの一覧をターミナルに表示する。

---

### マクロステータス表示

`!script` 実行中はターミナル右上に以下のように表示される。

```text
▶ macro: FILENAME   ■
```

`■` ボタンをクリックすると `!stop` 相当の停止処理が実行される。

## 5. 起動フラグ（関連）

| フラグ | 動作 |
|--------|------|
| `--orig` | `.orig.dsk`（原本）から読み込み、保存先は `.dsk` |
| `--no-save` | 終了時にディスクを保存しない |
| `--ro` | 全ドライブ読み取り専用 |
