# 24. Turbo Pascal 3 — 使い方

## 1. 概要

**Turbo Pascal 3**（Borland, 1984）は CP/M 上で動作する高速 Pascal コンパイラ。
このシミュレータの `TurboPascal3.dsk` は **Turbo Tutor** ディスク（サンプルコード集）で、
TURBO.COM（IDE 本体）も同梱されている。

| ファイル | 役割 |
|---------|------|
| `TURBO.COM` | IDE / コンパイラ本体 |
| `TURBO.OVR` | エディタ overlay（必須） |
| `TURBO.MSG` | エラーメッセージ |
| `TINST.COM` | 端末設定インストーラ |

---

## 2. 起動手順

### 2-1. ディスクをマウントする

シミュレータ UI の **B: Load** で `TurboPascal3.dsk` を選択する。

```
A>B:
B>TURBO
```

### 2-2. メイン画面

```
Logged drive: B
Active directory:
Work file:
Main file:

Edit        Compile     Run         Save
eXecute     Dir         Quit        compiler Options
```

| キー | 動作 |
|------|------|
| `E`  | エディタを開く |
| `C`  | コンパイル（メモリへ） |
| `R`  | コンパイルして即実行 |
| `S`  | ソースファイルを保存 |
| `D`  | ディレクトリ表示 |
| `Q`  | 終了（CP/M に戻る） |

---

## 3. 最初のプログラム（HELLO.PAS）

### 3-1. ワークファイルを指定して実行

メイン画面で：

```
Work file name? HELLO    ← .PAS は省略可
```

→ `R`（Run）を押す。

```
Compiling...
Running...
Hello, world!
```

### 3-2. コンパイルして .COM を生成

`O`（compiler Options）→ `C`（Compile to COM file）に設定してから `C`（Compile）。
`HELLO.COM` が生成され、`B>HELLO` で直接実行できる。

---

## 4. エディタのキー操作（WordStar 互換）

エディタは `E` で開く。このシミュレータの ^C / ^D / ^S / ^X / ^E ボタンが使える。

### カーソル移動

| キー | 動作 |
|------|------|
| `^E` | 上 |
| `^X` | 下 |
| `^S` | 左 |
| `^D` | 右 |
| `^A` | 単語左 |
| `^F` | 単語右 |
| `^W` | 1行スクロールアップ |
| `^Z` | 1行スクロールダウン |
| `^R` | 1ページ上 |
| `^C` | 1ページ下 |

### 編集

| キー | 動作 |
|------|------|
| `^G` | カーソル位置の文字削除 |
| `^Y` | 行削除 |
| `^N` | 改行挿入 |
| `^V` | 挿入 / 上書き切替 |
| `^I` | タブ |

### ファイル操作（^K プレフィックス）

| キー | 動作 |
|------|------|
| `^K S` | 保存して編集続行 |
| `^K D` | 保存してメイン画面へ |
| `^K Q` | 保存せずメイン画面へ |
| `^K B` | ブロック開始マーク |
| `^K K` | ブロック終了マーク |
| `^K C` | ブロックコピー |
| `^K Y` | ブロック削除 |

### 検索・置換（^Q プレフィックス）

| キー | 動作 |
|------|------|
| `^Q F` | 検索 |
| `^Q A` | 検索して置換 |

---

## 5. 新しいプログラムを書く

メイン画面で：

```
Work file name? MYTEST    ← 新ファイル名
```

`E` でエディタが開く（空白）。

```pascal
program MyTest;
begin
  writeln('Hello from 8080!');
end.
```

`^K D` → 保存してメイン画面へ。`R` でコンパイル＆実行。

---

## 6. サンプルプログラム一覧（Turbo Tutor 収録）

| ファイル | 内容 |
|---------|------|
| `HELLO.PAS` | 最小サンプル |
| `MYNAME.PAS` | 名前入力の例 |
| `GAME1.PAS` | 簡単なゲーム |
| `RANDOM.PAS` | 乱数 |
| `CPMDIR.PAS` | CP/M ディレクトリ読取り |
| `CPMSTAT.PAS` | CP/M システム状態取得 |
| `LISTT.PAS` | ソースリスタ（大規模サンプル） |

---

## 7. トラブルシューティング

| 症状 | 原因と対処 |
|------|-----------|
| `TURBO` 起動後すぐ終了 | `TURBO.OVR` がディスクにない → `doCopyAllToDisk.sh` 再実行 |
| エラー番号のみ表示 | `TURBO.MSG` がない → 同上 |
| 画面が乱れる | 端末設定が合っていない → `TINST` で端末タイプを再設定 |
| コンパイル時 `Disk full` | 作業ドライブを A: に変更、または別ディスクを用意 |
