# 60. Intel 8080 独自信号解説

Intel 8080 には他の CPU（Z80・6502・68000 等）には存在しない、
あるいは異なる設計思想で実装された信号がいくつかある。
本稿では vm80a Logic Analyzer で観測できる信号を中心に解説する。

---

## 1. SYNC — ステータスバイト期間通知

### 概要

```text
SYNC=1: T1（各マシンサイクルの先頭クロック）
SYNC=0: T2 以降
```

各マシンサイクルの **T1 クロックだけ High** になるパルス信号。
CPU は SYNC=1 の期間だけデータバスに**ステータスバイト**を出力する。

外部ハードウェア（Intel 8228 Bus Controller）はこのパルスをラッチのストローブとして使い、
データバスからステータス情報を取り込む。

### 他 CPU との比較

| CPU | 同等の信号 | 方式 |
|-----|-----------|------|
| 8080 | **SYNC** | データバスにステータスを乗せ、SYNC がラッチタイミングを通知 |
| Z80 | /M1, /MREQ, /IORQ | 専用ピンでサイクル種別を直接表現。SYNC 相当なし |
| 8085 | ALE | アドレス（下位8ビット）のラッチタイミング通知に転用。ステータス目的ではない |
| 6502 | なし | PHI2 がバス有効の確認に使われるが、ステータス通知目的ではない |

### vm80a での観測

Logic Analyzer の `SYNC` 行で各マシンサイクルの T1 を一目で識別できる。
SYNC の立ち上がりエッジ = 新しいマシンサイクルの開始 = M-CYC デコードの区切り。

---

## 2. DBIN — データバス入力要求

### 概要

```text
DBIN=1: CPU がデータバスからデータを読み取る期間（T2–T3）
DBIN=0: CPU はデータバスをドライブするか、バスは未使用
```

CPU がメモリや I/O デバイスにデータを要求していることを示す出力信号。
メモリはこの信号が High の間にデータバスへデータを出力すればよい。

8080 では **Active High（正論理）** であることが特徴的。

### 他 CPU との比較

| CPU | 同等の信号 | 極性 |
|-----|-----------|------|
| 8080 | **DBIN** | **Active High**（H でデータ入力） |
| Z80 | /RD | Active Low（L でデータ読み出し） |
| 8085 | /RD | Active Low |
| 6502 | R/W̄ | High=Read, Low=Write（1本で双方向） |

Active High を採用した理由は 8080 設計当時のバスドライバ IC との相性による。
Z80 以降は Active Low が業界標準になった。

### vm80a での観測

Logic Analyzer の `DBIN` 行で T2–T3 のデータ読み取りウィンドウを確認できる。
`dbus` が意味のあるデータ（オペコード・即値・メモリ内容）を示すのは DBIN=1 の期間のみ。

---

## 3. WR̄ (WR_N) — データ書き込み

### 概要

```text
WR_N=0 (Low): CPU がデータバスへデータを書き出している（メモリ・I/O 書き込み）
WR_N=1 (High): 非書き込み
```

メモリや I/O への書き込みサイクルで Low になる出力信号。
DBIN と相補的な関係にある（同時に両方 Active になることはない）。

### 他 CPU との比較

| CPU | 同等の信号 | 備考 |
|-----|-----------|------|
| 8080 | **WR̄ (Active Low)** | DBIN と組み合わせてバス方向を制御 |
| Z80 | /WR (Active Low) | 同様 |
| 8085 | /WR (Active Low) | 同様 |
| 6502 | R/W̄ | Read=High / Write=Low の 1 本で双方向表現 |

---

## 4. WAIT — ウェイトステート挿入

### 概要

```text
WAIT=1: CPU は T2 の後に Tw（ウェイトステート）を挿入して待機
WAIT=0: 通常動作
```

低速メモリや低速 I/O デバイスが CPU に「まだ準備できていない」と伝える信号。
T2 の立ち下がりエッジでサンプリングされ、High なら T3 への遷移を遅らせる。

CP/M システムでは DRAM・UARTなど低速デバイスのタイミング調整に不可欠だった。

### 他 CPU との比較

| CPU | 同等の信号 | 備考 |
|-----|-----------|------|
| 8080 | **WAIT (Active High)** | 入力、Low = Ready |
| Z80 | /WAIT (Active Low) | 極性が逆 |
| 8085 | READY (Active High) | 名称が異なるが機能は同じ |
| 6502 | RDY | Active High、PHI2 前半で評価 |

---

## 5. HLDA — バス解放応答（DMA 対応）

### 概要

```text
HOLD 入力が High → CPU は次の T3/T4 またはマシンサイクル境界でバスを解放
HLDA=1: CPU がアドレス・データバスを三状態（Hi-Z）にして解放完了を通知
```

DMA コントローラがバスを乗っ取るための仕組み。

1. DMA コントローラが **HOLD** 入力を High にする
2. CPU は現在のマシンサイクルを完了後、バスを Hi-Z にする
3. CPU が **HLDA** を High にして解放完了を通知
4. DMA がバスを制御してメモリ転送を行う
5. DMA が HOLD を Low に戻す → CPU が HLDA を Low にして再開

### 他 CPU との比較

| CPU | HOLD 相当 | HLDA 相当 |
|-----|----------|----------|
| 8080 | **HOLD** | **HLDA** |
| Z80 | BUSRQ | BUSAK |
| 8085 | HOLD | HLDA（同名） |
| 6502 | RDY（兼用） | なし（バス解放の専用機構なし） |

---

## 6. INTE — 割り込み許可状態の出力

### 概要

```text
INTE=1: EI 命令実行後（割り込み許可状態）
INTE=0: DI 命令実行後（割り込み禁止状態）
```

CPU の割り込み許可フラグ（IFF）の現在状態を外部に出力する信号。
外部ハードウェアが割り込みコントローラの動作を制御するために参照する。

Z80 では IFF1/IFF2 は内部状態で、外部出力はされない（デバッガ等で読み出し不可）。
**8080 が外部に公開している点が独特**。

### 他 CPU との比較

| CPU | 同等の信号 | 備考 |
|-----|-----------|------|
| 8080 | **INTE（外部出力あり）** | リアルタイムで割り込み許可状態を観測可能 |
| Z80 | なし（内部 IFF1/IFF2） | 外部から直接観測不可 |
| 8085 | なし（SID/SOD は別目的） | |
| 6502 | なし（内部フラグ I ビット） | |

## 7. vm80a でのリングバッファ信号対応

| 信号名 | ring.mjs フィールド | Word | ビット |
|--------|---------------------|------|--------|
| SYNC | `sync` | 0 | bit 9 |
| DBIN | `dbin` | 0 | bit 8 |
| WR̄ | `wr_n` | 0 | bit 10 |
| HLDA | `hlda` | 0 | bit 11 |
| WAIT | `wait` | 0 | bit 12 |
| INTE | `inte` | 0 | bit 13 |
| MEMR | `memr` | 0 | bit 14 |
| MEMW | `memw` | 0 | bit 15 |
| status_byte | `status_byte` | 4 | bits 7:0 |

Logic Analyzer でこれらを有効にすると、各マシンサイクルの制御フローを
クロック単位で可視化できる。**これはソフト FPGA 固有の優位性**であり、
8080 エミュレータでは観測不可能な内部バス制御信号をリアルタイムで見られる。

---

## 8. まとめ

| 信号 | 8080 の独自性 | 後継での変化 |
|------|--------------|-------------|
| **SYNC** | データバス多重の核心、T1 ステータス期間を通知 | Z80 では廃止（/M1 等の専用ピンに分解） |
| **DBIN** | Active High でデータ入力要求 | Z80 では /RD (Active Low) に変更 |
| **WR̄** | Active Low の書き込み通知 | Z80 同様だが 6502 では R/W̄ 1 本に統合 |
| **WAIT** | Active High でウェイト挿入 | Z80 では /WAIT (Active Low) に |
| **HLDA** | DMA 対応のバス解放応答 | Z80 では BUSAK に改名 |
| **INTE** | 割り込み許可状態を外部出力 | Z80 では非公開（内部 IFF1/IFF2 のみ） |
