# 23. WordMaster 使い方

WordMaster（`WM.COM`）は MicroPro 社製の CP/M 用全画面テキストエディタ。
WordStar の前身であり、同じダイヤモンドキー操作体系を持つ。

## 起動

```
WM ファイル名.TXT
```

ファイルが存在しない場合は新規作成される。

## 1. カーソル移動

```
        ^E (上)
         |
^S (左) -+- ^D (右)
         |
        ^X (下)
```

| キー | 動作 |
|------|------|
| `^E` | 上1行 |
| `^X` | 下1行 |
| `^S` | 左1文字 |
| `^D` | 右1文字 |
| `^A` | 左1単語 |
| `^F` | 右1単語 |
| `^Q S` | 行頭 |
| `^Q D` | 行末 |
| `^Q E` | 画面上端 |
| `^Q X` | 画面下端 |
| `^Q R` | ファイル先頭 |
| `^Q C` | ファイル末尾 |

## 2. 削除

| キー | 動作 |
|------|------|
| `^G` | カーソル位置の文字を削除 |
| `^H` / BS | カーソル左の文字を削除 |
| `^T` | カーソル右の単語を削除 |
| `^Y` | 現在行を削除 |

## 3. 挿入モード

| キー | 動作 |
|------|------|
| `^V` | 挿入モード ↔ 上書きモード 切り替え |

## 4. ブロック操作

| キー | 動作 |
|------|------|
| `^K B` | ブロック開始マーク |
| `^K K` | ブロック終了マーク |
| `^K C` | マークブロックをコピー（カーソル位置へ）|
| `^K V` | マークブロックを移動（カーソル位置へ）|
| `^K Y` | マークブロックを削除 |
| `^K H` | ブロックマーク解除 |

## 5. 検索・置換

| キー | 動作 |
|------|------|
| `^Q F` | 文字列検索 |
| `^Q A` | 検索して置換 |
| `^L` | 直前の検索／置換を繰り返す |

オプション（検索プロンプトで入力）:
- `B` — 逆方向検索
- `G` — ファイル全体（先頭から）
- `N` — 確認なしで全置換
- 数字 — 指定回数だけ実行

## 6. 保存・終了

| キー | 動作 |
|------|------|
| `^K S` | 保存して編集継続（バックアップ作成）|
| `^K D` | 保存して終了 |
| `^K X` | 保存して終了（`^K D` と同義）|
| `^K Q` | 変更を破棄して終了 |

## 7. その他

| キー | 動作 |
|------|------|
| `^J` | ヘルプ画面表示 |
| `^B` | 段落の折り返し整形（右マージン幅に合わせる）|
| `^I` / Tab | タブ挿入 |
| `^P` + 文字 | 制御文字を埋め込む（プリンタ制御など）|
| `^U` | コマンド中断 |

## 8. 本シミュレータでの注意

- `^C`（CP/M BREAK）はターミナルの **`^C` ボタン**から送信する。
- BS キーは xterm.js が `^H`（0x08）に変換して送信される。
- WordMaster 起動中は CP/M のコンソールステータスポート（Port 0x02）を
  ポーリングしてキー入力を待機する。I/O Bus Analyzer で `port=0x02` の
  アクセスが続いていれば正常動作。
