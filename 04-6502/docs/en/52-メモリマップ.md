# 52. Apple-1 Memory Map (Woz Monitor + Integer BASIC)

## 1. Full Map (64KB Address Space)

```text
Address            Size     Contents
─────────────────────────────────────────────────────
$0000–$00FF        256 B   Zero page (fast 6502 access)
$0100–$01FF        256 B   6502 hardware stack
$0200–$027F        128 B   Woz Monitor input buffer (GETLINE)
$0280–$0FFF       ~3.5 KB  BASIC program area and variables (RAM)
$1000–$CFFF         ─      Not implemented (undefined on access)
$D010–$D013          4 B   PIA (6821) — keyboard and display I/O
$D014–$DFFF         ─      PIA mirrors / unused
$E000–$EFFF        4 KB    Integer BASIC ROM
$F000–$FEFF         ─      Not implemented
$FF00–$FFFF        256 B   Woz Monitor ROM
```

> Standard Apple-1 RAM covers $0000–$0FFF (4 KB); expansion boards provide up to 8 KB.

---

## 2. I/O — PIA (6821) Registers

| Address | Name | Direction | Description |
|---------|------|-----------|-------------|
| `$D010` | KBD | R | Keyboard data (bit 7 = 1 indicates a new key) |
| `$D011` | KBDCR | R/W | Keyboard control register (bit 7 = key ready flag) |
| `$D012` | DSP | W | Display data (bit 7 = 1 triggers write) |
| `$D013` | DSPCR | R/W | Display control register |

- Keyboard: strobe on PIA CA1 → KBDCR.bit7 set → read KBD → flag is cleared
- Display: write ASCII to DSP (with bit 7 set) → PIA transfers to 7-seg / TV output

---

## 3. 6502 Vectors (End of ROM)

| Address | Vector | Points to |
|---------|--------|-----------|
| `$FFFA–$FFFB` | NMI | (not used on Apple-1) |
| `$FFFC–$FFFD` | RESET | `$FF00` (Woz Monitor entry) |
| `$FFFE–$FFFF` | IRQ/BRK | `$FF00` or Monitor handler |

---

## 4. Woz Monitor ($FF00–$FFFF)

### 4.1 Main Entry Points

| Address | Label | Function |
|---------|-------|----------|
| `$FF00` | RESET | Monitor startup and initialization |
| `$FFEF` | ECHO | Output one character (A register → DSP) |
| `$FFDC` | PRHEX | Output lower 4 bits of A as 1 hex digit |
| `$FFE5` | PRBYTE | Output A as 2 hex digits |
| `$FFEB` | PRADR | Output XAMH:XAML in "XXXX:" format |

> Addresses are based on the Woz Monitor source (included in the Apple-1 Operation Manual).
> Ports and FPGA implementations may differ slightly.

### 4.2 Zero Page Variables ($24–$2B)

| Address | Label | Description |
|---------|-------|-------------|
| `$24` | XAML | Low byte of examine/store address |
| `$25` | XAMH | High byte of examine/store address |
| `$26` | STL | Low byte of store destination address |
| `$27` | STH | High byte of store destination address |
| `$28` | L | General-purpose temporary (low) |
| `$29` | H | General-purpose temporary (high) |
| `$2A` | YSAV | Y register save |
| `$2B` | MODE | Operating mode (`$00`=XAMMODE / `$EE`=STOREMODE) |

### 4.3 Input Buffer

- `$0200–$027F` (128 B): buffer for receiving one line in `GETLINE`

## 5. Integer BASIC ROM ($E000–$EFFF)

### 5.1 Main Entry Points

| Address | Function |
|---------|----------|
| `$E000` | BASIC cold start (equivalent to NEW; full initialization) |
| `$E2B3` | BASIC warm start (restart while preserving the program) ※ |

> ※ The warm start address may vary by implementation; verify against the source.

### 5.2 BASIC Zero Page Usage (Excerpt)

BASIC uses the region around $00–$4F extensively. Key pointers:

| Address | Purpose |
|---------|---------|
| `$00–$01` | Program counter (text pointer) |
| `$02–$03` | LOMEM (start of program text) |
| `$04–$05` | HIMEM (top of variable area) |
| `$06–$07` | Variable table start |
| `$08–$09` | FOR-NEXT stack pointer |
| `$3A–$3B` | Current line number |

> For full details, refer to the Apple-1 BASIC source listing (handwritten by Woz).
> The zero page is densely used; BASIC avoids $24–$2B to prevent conflicts with Woz Monitor.

### 5.3 BASIC Memory Layout (at Runtime)

```text
$0280          LOMEM (start of program text)
  ↓
  Program text
  (each line: 2B line number + 1B length + token stream + $00)
  ↓
  Variable table (2B name + 2B value = 4B per variable)
  ↓
  Array table
  ↓
  Free space
  ↑
$0FFF          HIMEM (end of 4KB RAM)
```

- Total limit for program + variables + arrays: approximately 500 B (see §11 of [51-integer-BASIC-文法リファレンス.md](51-integer-BASIC-文法リファレンス.md))

---

## 6. Implications for Address Decoder Design

Minimum decoding required when implementing Apple-1 on a soft-FPGA:

| Select condition | Chip / Function |
|------------------|----------------|
| A15:A12 = `0000`–`0FFF` | RAM (4 KB) |
| A15:A4 = `1101 0000 0001` (`$D01x`) | PIA |
| A15:A12 = `1110` (`$E000`–`$EFFF`) | BASIC ROM |
| A15:A8 = `1111 1111` (`$FF00`–`$FFFF`) | Woz Monitor ROM |
