# 52. Memory Map

## 1. CP/M 2.2 Standard Memory Layout (64 KB)

| Address | Size | Purpose |
|---------|------|---------|
| $0000–$00FF | 256 B | Page 0 (restart vectors, BDOS entry) |
| $0100–$DBFF | 55 KB | TPA (Transient Program Area) |
| $DC00–$E3FF | 2 KB | CCP (Console Command Processor) |
| $E400–$F1FF | 3.5 KB | BDOS (Basic Disk Operating System) |
| $F200–$FFFF | 3.5 KB | BIOS (Basic I/O System) |

## 2. Page 0 Details

| Address | Contents |
|---------|----------|
| $0000–$0002 | `JMP WBOOT` (warm boot vector) |
| $0003 | IOBYTE (I/O assignment, optional) |
| $0004 | Current disk number |
| $0005–$0007 | `JMP BDOS+6` (BDOS entry point) |
| $0008–$003F | Restart vectors RST1–RST7 (8080 interrupts) |
| $0040–$00FF | Scratch area |

## 3. I/O Port Map

Legend: ★ = CP/M BIOS conventional port　☆ = project-specific port

### 3.1 Console

| Port | Dir | Symbol | Purpose | Type |
|------|-----|--------|---------|------|
| $00 | IN | CONIN | Console input (read 1 byte) | ★ |
| $01 | OUT | CONOUT | Console output (send 1 byte) | ★ |
| $02 | IN | CONST | Console status (0=none / 1=available) | ★ |

### 3.2 Disk

| Port | Dir | Symbol | Purpose | Type |
|------|-----|--------|---------|------|
| $10 | OUT | DCMD | Disk command (0=READ / 1=WRITE) | ★ |
| $10 | IN | DSTS | Disk status (always 0=OK) | ★ |
| $11 | OUT | DTRK | Track number | ★ |
| $12 | OUT | DSEC | Sector number (0-indexed, after SECTRAN) | ★ |
| $13 | OUT | DDMA\_L | DMA address low byte | ★ |
| $14 | OUT | DDMA\_H | DMA address high byte | ★ |
| $15 | OUT | DDRV | Drive select (0=A: / 1=B: / 2=C:, set by SELDSK) | ☆ |

### 3.3 System Control

| Port | Dir | Symbol | Purpose | Type |
|------|-----|--------|---------|------|
| $20 | OUT | WBOOT | Warm boot (restore CCP+BDOS from initial image) | ☆ |

### 3.4 Cycle Counter and Frequency Measurement

| Port | Dir | Symbol | Purpose | Type |
|------|-----|--------|---------|------|
| $30 | OUT | CRST | Cycle counter reset | ☆ |
| $30 | IN | CLO | Counter latch + read (low 8 bits) | ☆ |
| $31 | IN | CMI | Counter read (bits 15–8) | ☆ |
| $32 | IN | CMH | Counter read (bits 23–16) | ☆ |
| $33 | IN | CHI | Counter read (bits 31–24) | ☆ |
| $34 | OUT | FSTA | Start frequency measurement (record wall clock + counter) | ☆ |
| $34 | IN | FLO | Measured frequency MHz low byte | ☆ |
| $35 | IN | FHI | Measured frequency MHz high byte | ☆ |
| $36 | IN | FKL | Measured frequency kHz fraction (0–999) | ☆ |
| $37 | IN | FHL | Measured frequency Hz fraction (0–999) | ☆ |
| $38 | OUT | FLAT | Frequency latch commit (compute Hz from elapsed time) | ☆ |

### 3.5 Host File Transfer (R.COM / W.COM)

| Port | Dir | Symbol | Purpose | Type |
|------|-----|--------|---------|------|
| $A1 | OUT | HCMD | Host command (`~C` specifies BDOS function number) | ☆ |
| $A1 | IN | HRES | Command result (0x00=success / 0xFF=failure) | ☆ |

## 4. Disk Parameters (Standard 8-inch SSSD)

| Item | Value | Formula |
|------|-------|---------|
| SPT (sectors/track) | 26 | — |
| Sector size | 128 B | — |

| Block size | 1 KB | 2^BSH × 128 B |
| Total capacity | 256 KB | 77 × 26 × 128 |
