## 1. Unix V6 の構造を理解する（一次資料）

### Lions' Commentary on UNIX 6th Edition（John Lions, 1977）

Unix V6 カーネルのソースコードと詳細な注釈を収録した歴史的資料。
カーネルの proc テーブル・スケジューラ・デバイスドライバ・システムコールの
仕組みを行単位で解説する唯一の一次資料。

- Archive.org 版: [lions-commentary-on-unix-6th-edition](https://archive.org/details/lionscommentaryo00lion)
- TUHS ソースコード: [V6/usr/sys/](https://www.tuhs.org/cgi-bin/utree.pl?act=get&file=V6/usr/sys)

soft-FPGA での活用:

- 割り込みルーティン（`clock.c`・`rk.c`）でどのバスサイクルが発生するかを把握
- `main.c` の `printf("mem=")` 出力アドレスを PC トリガーに設定する際の根拠
- fork/exec によるプロセス切り替えで MMU PAR がどう書き換わるかを読み取る

### TUHS（The Unix Heritage Society）

Unix V6 のオリジナルソースコードおよびマニュアルページのアーカイブ。

- [TUHS — Unix V6 ファイルツリー](https://www.tuhs.org/cgi-bin/utree.pl?act=get&file=V6)

## 4. SIMH — ソフトウェアシミュレータとの比較

### SIMH PDP-11 シミュレータ

Digital Equipment Corporation の歴史的コンピュータを再現するソフトウェアシミュレータ群。
PDP-11/Unix V6 のブート確認・ディスクイメージ作成に使用する。

```bash
# Ubuntu/WSL2 でのインストール
sudo apt install simh

# PDP-11 起動（最小設定）
pdp11
sim> attach rk0 unix_v6_rk05.dsk
sim> boot rk0
```

soft-FPGA との違い:

| 比較項目 | SIMH | soft-FPGA（このプロジェクト）|
|---------|------|---------------------------|
| 実行速度 | 実時間の数千倍 | 実機の約 10–100 倍（WASM）|
| バス波形 | 不可視 | Logic Analyzer で観測可能 |
| MMU 内部状態 | 不可視 | パネルでリアルタイム表示 |
| トラップ原因 | ログ依存 | TRAP 信号で検出 |
| 用途 | 動作確認・デバッグ | 教育・可視化デモ |

## 6. バスタイミング・アドレッシングの補足資料

### PDP-11 アーキテクチャまとめ（Wikipedia）

- [PDP-11 — Wikipedia](https://ja.wikipedia.org/wiki/PDP-11)

オルソゴナル命令セット・アドレッシングモードの概要を素早く確認するのに向く。

### rtlscope 設計上の活用ポイント

これらの資料を読む目的は、
**「Unix V6 のどの処理がどのバスサイクルを発生させるか」を Logic Analyzer で可視化する**
設計を考えることにある。

- PDP-11 Processor Handbook でバスサイクルタイミング（DATO/DATI）を把握
- Lions' Commentary でシステムコール・割り込みルーティンの PC 遷移を追う
- SIMH で動作確認しながら、soft-FPGA で内部信号を観測する
- cpus-pdp11 ソースで特定の信号がどの条件で変化するかを読む

これらが揃うことで、Logic Analyzer 上の波形と Unix V6 カーネルの動作が対応できるようになる。
