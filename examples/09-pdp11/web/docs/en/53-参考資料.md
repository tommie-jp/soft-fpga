## 1. Understanding Unix V6 Internals (Primary Sources)

### Lions' Commentary on UNIX 6th Edition (John Lions, 1977)

A historic document containing the Unix V6 kernel source code with detailed annotations.
The definitive primary reference covering the kernel's proc table, scheduler, device drivers,
and system call mechanisms line by line.

- Archive.org edition: [lions-commentary-on-unix-6th-edition](https://archive.org/details/lionscommentaryo00lion)
- TUHS source code: [V6/usr/sys/](https://www.tuhs.org/cgi-bin/utree.pl?act=get&file=V6/usr/sys)

How it is used in soft-FPGA:

- Understanding which bus cycles are generated by interrupt routines (`clock.c`, `rk.c`)
- Basis for setting the PC trigger at the address printed by `printf("mem=")` in `main.c`
- Reading how MMU PAR is rewritten during process switches via fork/exec

### TUHS (The Unix Heritage Society)

Archive of Unix V6 original source code and manual pages.

- [TUHS — Unix V6 file tree](https://www.tuhs.org/cgi-bin/utree.pl?act=get&file=V6)
- [Unix V6 Man Pages](https://www.tuhs.org/cgi-bin/utree.pl?act=get&file=V6/usr/man)

## 2. PDP-11 Hardware Reference (Original Documents)

### PDP-11 Processor Handbook (DEC, 1975)

The primary reference documenting the PDP-11/40 instruction set, addressing modes,
bus timing, and MMU (KT11) specifications.

- [bitsavers.org — PDP-11/40 Processor Handbook](http://bitsavers.org/pdf/dec/pdp11/handbooks/PDP1140_Processor_Handbook_1974.pdf)

Key sections to review:

| Section | Content |
|---------|---------|
| Chapter 3 | Full instruction set listing (byte count, cycle count, flags) |
| Chapter 4 | Details of all 8 addressing modes |
| Chapter 6 | Bus cycle timing (DATO/DATI cycles) |
| Chapter 8 | KT11-C MMU — PAR/PDR structure and mapping calculation |

### PDP-11 Peripherals Handbook (DEC, 1975)

The original reference for RK11, DL11, and KW11 register specifications and interrupt sequences.

- [bitsavers.org — PDP-11 Peripherals Handbook](http://bitsavers.org/pdf/dec/pdp11/handbooks/)

## 3. RTL Core (cpus-pdp11)

### Brad Parker "cpus-pdp11"

An RTL implementation that reproduces the PDP-11/40 microsequencer in Verilog.
This is the upstream repository for the core used by this project.

- [GitHub — bholt/cpus-pdp11](https://github.com/bholt/cpus-pdp11) (fork source)
- Original: [GitHub — bparker06/cpus-pdp11](https://github.com/bparker06/cpus-pdp11)

Files useful for understanding the core structure:

| File | Content |
|------|---------|
| `rtl/pdp11.v` | CPU top level |
| `rtl/decode.v` | Instruction decode |
| `rtl/mmu.v` | KT11 MMU |
| `rtl/rk11.v` | RK11 disk controller |

## 4. SIMH — Comparison with Software Simulators

### SIMH PDP-11 Simulator

A collection of software simulators reproducing historic Digital Equipment Corporation computers.
Used for boot verification and disk image creation for PDP-11 / Unix V6.

```bash
# Install on Ubuntu/WSL2
sudo apt install simh

# Boot PDP-11 (minimal configuration)
pdp11
sim> attach rk0 unix_v6_rk05.dsk
sim> boot rk0
```

Differences from soft-FPGA:

| Comparison | SIMH | soft-FPGA (this project) |
|-----------|------|--------------------------|
| Execution speed | Several thousand times real time | ~10–100x actual hardware (WASM) |
| Bus waveforms | Not visible | Observable in Logic Analyzer |
| MMU internal state | Not visible | Real-time display in panel |
| Trap cause | Log-dependent | Detected via TRAP signal |
| Use case | Functional verification / debugging | Education / visualization demo |

### How These References Are Used in rtlscope Design

The purpose of reading these materials is to inform the design of
**visualizing which Unix V6 operations generate which bus cycles in the Logic Analyzer**.

- Use the PDP-11 Processor Handbook to understand bus cycle timing (DATO/DATI)
- Use Lions' Commentary to trace PC transitions through system calls and interrupt routines
- Verify behavior with SIMH while observing internal signals in soft-FPGA
- Read the cpus-pdp11 source to understand under what conditions specific signals change

With all of these in hand, waveforms in the Logic Analyzer can be correlated with Unix V6 kernel behavior.
