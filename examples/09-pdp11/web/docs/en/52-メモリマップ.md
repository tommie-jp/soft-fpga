## 1. PDP-11 Address Spaces

The PDP-11 has two address spaces: **virtual (16-bit)** and **physical (18-bit)**.

| Space | Width | Capacity | Description |
|-------|-------|----------|-------------|
| Virtual address | 16 bits | 64 KB | Address directly referenced by the CPU. Independent per mode |
| Physical address (Unibus) | 18 bits | 256 KB | Real memory + device addresses after MMU translation |

## 2. Virtual Address Space (64 KB, 8 pages × 8 KB)

The MMU maps each 8 KB region independently to physical addresses.
Kernel mode and user mode each have independent mapping tables (I-space).

| Page | Virtual Address | Virtual Size | Role in Unix V6 |
|------|----------------|--------------|-----------------|
| 7 | `0o160000`–`0o177777` | 8 KB | I/O page (Unibus device registers, Kernel only) |
| 6 | `0o140000`–`0o157777` | 8 KB | Kernel stack (Kernel) / User stack (User) |
| 5 | `0o120000`–`0o137777` | 8 KB | — |
| 4 | `0o100000`–`0o117777` | 8 KB | — |
| 3 | `0o060000`–`0o077777` | 8 KB | — |
| 2 | `0o040000`–`0o057777` | 8 KB | — |
| 1 | `0o020000`–`0o037777` | 8 KB | — |
| 0 | `0o000000`–`0o017777` | 8 KB | Kernel code / start of user code |

Page 7 virtual `0o160000`–`0o177777` is fixed-mapped to the I/O page in Kernel mode,
and is inaccessible from User mode (protection fault).

## 3. Physical Address Space (Unibus 256 KB)

| Physical Address (octal) | Physical Address (hex) | Usage |
|--------------------------|------------------------|-------|
| `0o000000`–`0o737777` | `0x0000`–`0xF7FF` | RAM (up to 248 KB) |
| `0o740000`–`0o757777` | `0xF800`–`0xFBFF` | Reserved (unused in this implementation) |
| `0o760000`–`0o777777` | `0xFC00`–`0xFFFF` | I/O page (Unibus device registers) |

This simulator has **128 KB** of RAM (`0o000000`–`0o377777`).

## 4. Unix V6 Kernel Memory Layout (after boot)

| Physical Address (octal) | Usage |
|--------------------------|-------|
| `0o000000`–`0o000777` | Trap and interrupt vector table (512 bytes) |
| `0o001000`–... | Unix V6 kernel code (`text` segment) |
| ...–`0o175777` | Kernel data, BSS, and stack |
| `0o176000`–`0o177777` | End of kernel stack (initial SP) |

## 5. Interrupt and Trap Vector Table

Fixed at physical/virtual `0o000000`–`0o000777`. Each vector is 2 words (PC + PSW).

| Vector (octal) | Assignment |
|----------------|------------|
| `0o000004` | Bus error (timeout / alignment) |
| `0o000010` | Illegal instruction trap |
| `0o000014` | BPT (breakpoint trap) |
| `0o000020` | IOT instruction |
| `0o000024` | Power failure |
| `0o000030` | EMT instruction (emulator trap) |
| `0o000034` | TRAP instruction (system call) |
| `0o000060` | DL11 receive (TTY RX) |
| `0o000064` | DL11 transmit (TTY TX) |
| `0o000100` | KW11 line clock (60 Hz) |
| `0o000220` | RK11 disk transfer complete |

## 6. I/O Page — Unibus Device Registers

Physical `0o760000`–`0o777777` (= virtual Kernel page 7).
The CPU in Kernel mode reads and writes this range to control devices.

### 6.1 DL11 (Serial Console)

| Address (octal) | Address (hex) | Register | Description |
|-----------------|---------------|----------|-------------|
| `0o177560` | `0xFFB0` | RCSR | Receive control/status (bit 7 = RDONE) |
| `0o177562` | `0xFFB2` | RBUF | Receive buffer (lower 8 bits = received character) |
| `0o177564` | `0xFFB4` | XCSR | Transmit control/status (bit 7 = XRDY) |
| `0o177566` | `0xFFB6` | XBUF | Transmit buffer (write to send) |

### 6.2 KW11 (Line Clock, 60 Hz)

| Address (octal) | Address (hex) | Register | Description |
|-----------------|---------------|----------|-------------|
| `0o177546` | `0xFF66` | LKS | Line clock control/status (bit 6 = IE, bit 7 = DONE) |

### 6.3 RK11 (RK05 Disk Controller)

| Address (octal) | Address (hex) | Register | Description |
|-----------------|---------------|----------|-------------|
| `0o177400` | `0xFF00` | RKDS | Drive status |
| `0o177402` | `0xFF02` | RKER | Error register |
| `0o177404` | `0xFF04` | RKCS | Control/status (bit 0 = GO, bit[3:1] = Function) |
| `0o177406` | `0xFF06` | RKWC | Word count (two's complement) |
| `0o177410` | `0xFF08` | RKBA | Bus address (lower 16 bits) |
| `0o177412` | `0xFF0A` | RKDA | Disk address (drive/cylinder/sector) |

### 6.4 MMU Registers

| Address (octal) | Address (hex) | Description |
|-----------------|---------------|-------------|
| `0o172300`–`0o172317` | `0xFF4C`–`0xFF5F` | Kernel I-space PAR (0–7) |
| `0o172340`–`0o172357` | `0xFF60`–`0xFF6F` | Kernel I-space PDR (0–7) |
| `0o177600`–`0o177617` | `0xFF80`–`0xFF8F` | User I-space PAR (0–7) |
| `0o177640`–`0o177657` | `0xFF90`–`0xFF9F` | User I-space PDR (0–7) |
| `0o177572` | `0xFFBA` | SR0 (MMU status, bit 0 = MMU Enable) |
| `0o177576` | `0xFFBE` | SR3 (extended feature flags) |
