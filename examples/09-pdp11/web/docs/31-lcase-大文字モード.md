# 31. LCASE（大文字モード）の挙動

## 1. 症状

Unix V6 ログイン後、入力・出力がすべて大文字になる。

```text
login: ROOT
# WHOAMI
WHOAMI: NOT FOUND
# LS /
BIN  DEV  ETC  ...
```

## 2. 原因

Unix V6 の tty ドライバには **LCASE モード**（小文字端末対応）がある。
大文字専用テレタイプ端末のための機能で、以下の変換を行う。

| 方向 | 変換 |
|------|------|
| 入力 | `a`→`A` としてエコー（カーネル内部では`a`に戻してプログラムへ渡す） |
| 出力 | プログラムの`a`→端末には`A`として送る |

`login` プログラムはユーザー名が**全大文字**で入力されると
「大文字専用端末だ」と判断し、自動的に LCASE をセットする。

## 3. 発動条件

```text
login:          ← 空 Enter → LOGIN INCORRECT
NAME: ROOT      ← 2回目で "ROOT" と打つ → LCASE 発動
#
```

最初のログインで大文字（`ROOT`）を入力すると LCASE が有効になる。
**小文字**で `root` と打てば発動しない。

## 4. 解除方法

ログイン後に以下を入力（LCASE 中でも大文字入力をカーネルが小文字に変換するので動く）：

```text
# STTY -LCASE
```

以降は小文字表示に戻る。

## 5. 正しいログイン手順

```text
login: root     ← 小文字で入力
Password:       ← 空 Enter（root はパスワードなし）
#               ← LCASE 発動なし、小文字で動作
```

## 6. 歴史的背景

LCASE は Unix V6 / V7 時代のテレタイプ端末（Model 33 ASR 等）への対応機能。
これらの端末は大文字しか印字できなかった。
現代の端末エミュレータでこの機能が発動すると「バグ」に見えるが、仕様通りの動作。
