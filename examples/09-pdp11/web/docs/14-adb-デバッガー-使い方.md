# 14. db / adb — Unix V6 デバッガの使い方

このディスクイメージには `/bin/db`（Unix V6 標準デバッガ）が収録されています。
`/bin/adb` はその **ハードリンク**（同一バイナリ）なので、どちらの名前でも使えます。

> Unix V6 の `db` は V7 以降の `adb`（Absolute DeBugger）の前身です。
> コマンド体系はほぼ同じですが、名前は `db` でした。

---

## 1. 起動

```text
# adb a.out
```

または:

```text
# db a.out
```

引数なし（オブジェクトのみ）でプロセスを新規生成します。
起動すると `adb:` プロンプトは表示されません。コマンドを直接入力します。

---

## 2. メモリ / 命令検査

書式: `address/format`

### 2.1 フォーマット文字

| 文字 | 説明 |
|------|------|
| `o` | 8 進ワード（16 ビット）|
| `d` | 10 進ワード |
| `x` | 16 進ワード |
| `c` | 1 文字（ASCII）|
| `s` | 文字列（NUL 終端）|
| `i` | PDP-11 命令（逆アセンブル）|

**繰り返し**: フォーマット後に数字で連続表示できます。

```text
4000/10i        4000 番地から 10 命令を逆アセンブル
0200/20o        0200 番地から 20 ワードを 8 進表示
```

**Enter** を押すと直前アドレスの次を表示します。

---

## 3. レジスタ表示

```text
$r
```

実行例:

```text
r0  003710     r1  013220
r2  000000     r3  000377
r4  001234     r5  017532
sp  177600     pc  004014
ps  030006
```

`ps` は PSW（Processor Status Word）、値は 8 進。

---

## 4. スタックトレース

```text
$C
```

C 関数呼び出しスタックを表示します。

---

## 5. 実行制御

| コマンド | 説明 |
|---------|------|
| `:r` | プロセスを開始（引数があれば `:r arg1 arg2`）|
| `:c` | ブレークポイント停止後に継続実行 |
| `:s` | 1 命令ステップ実行 |

---

## 6. ブレークポイント

```text
address:b       アドレス（8 進）にブレーク設置
_main:b         シンボルで指定（シンボルテーブルが必要）
$b              ブレークポイント一覧
address:d       削除
```

---

## 7. シンボル変換

```text
_main?          シンボル → アドレス（8 進）
4014=           アドレス → 最近傍シンボル名
```

---

## 8. シェルコマンド

```text
!ls             adb セッションを維持したまま Unix コマンドを実行
```

---

## 9. 終了

```text
$q
```

## 10. 典型的なデバッグ手順

### Hello, World をステップ実行する

1. プログラムを `cc` でコンパイルする（EDITOR ボタンを利用すると文字化けしない）。

   ```text
   # cc hello.c
   ```

2. `adb` を起動する。

   ```text
   # adb a.out
   ```

3. `main` にブレークポイントを設置して実行。

   ```text
   _main:b
   :r
   ```

4. ブレークポイントで停止したらレジスタを確認。

   ```text
   $r
   ```

5. 1 命令ずつ進める。

   ```text
   :s
   :s
   ```

6. PC 周辺の命令を逆アセンブルして確認。

   ```text
   4014/5i
   ```

7. 終了。

   ```text
   $q
   ```

---

## 11. a.out が "syntax error" になる場合

コマンドラインに直接テキストを貼り付けると UART が文字化けし、
cc がソースを正しく読めず壊れた `a.out` を生成することがあります。

**対処**: EDITOR ボタン（またはツールバーの `EDITOR`）でソースを入力してください。
`cat > hello.c` コマンドをペーシング送信するので文字化けしません。

## 12. Web UI デバッグパネルとの併用

`adb`/`db` は Unix プロセスレベルのデバッガです。
soft-FPGA の **Logic Analyzer** と **GPR パネル** は RTL（ハードウェア）レベルのデバッガです。

| ツール | 観測対象 | 粒度 |
|--------|---------|------|
| `adb` / `db` | プロセスのレジスタ・メモリ・コール | 命令レベル |
| GPR パネル | CPU レジスタのリアルタイム表示 | クロックレベル |
| Logic Analyzer | Unibus 信号・バスサイクル | クロックレベル |
