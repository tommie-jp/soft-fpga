**アーキテクチャ**: 式文字列 → `_trigParse`（UI）→ `trigCompileToWasm`（UI）→ `postMessage` → Worker 内で `new WebAssembly.Instance` → simLoop 毎フレームに全新着サンプルを Wasm ネイティブ評価（≈ 2–5 ns/sample）。Expr Set 時に `ring_tick_mask=0`（毎 tick サンプリング）へ自動切り替え。

**信号対応状況**:

| 比較種別 | 対応信号 | 非対応 |
|---------|---------|-------|
| 数値比較 `== != < > <= >=` | 全信号（VA, PC, RD, Mode, istate, ISN, PSW, R0-R5 等） | Cycle（仮想信号） |
| 文字列比較 | `Mode == "USER"/"KERNEL"/"SUPER"`, `istate == "F1"/"C1"` など | `ISN == "MOV …"`, `PSW == "…"`, `Cycle == "FETCH"` |
| エッジ検出 `.rising/.falling/.edge` | 全非仮想信号 | Cycle（仮想信号） |

**Cycle / ISN 文字列 / PSW 文字列の代替式**:

| やりたいこと | 代替式 |
|------------|-------|
| `Cycle == "FETCH"` | `RD.rising && istate == "F1"` |
| `Cycle == "MEM_RD"` | `RD == 1 && istate != "F1"` |
| `ISN == "CLR R1"` | `ISN == 0o5001` |
| `PSW` フラグ確認 | `PSW == 0o0340`（数値） |

**残課題**: Cycle（仮想信号）・ISN 文字列・PSW 文字列に対して Worker 内 JS フォールバック（`importScripts` + `_trigEvalExpr`）を追加すれば完全対応できる。現状はコンパイルエラーを表示して代替式を案内している。

### 7. V6 ディスクイメージのコマンド動作不良（2026-06-11 調査）

MCP Playwright で実機テストを実施。以下のコマンドが exec 失敗する。

#### 実行不可コマンド一覧

| コマンド | 場所 | 失敗様式 | 判明した原因 |
|---------|------|---------|------------|
| `dc` | `/bin/dc` | `dc: not found` | **バイナリ破損** — `file` が `data` と報告。a.out magic 不正 |
| `bc` | `/usr/bin/bc` | `bc: not found` | exec 失敗（原因未特定） |
| `chess` | `/usr/games/chess` | `not found` | exec 失敗（16088B, pure executable 形式）|
| `ttt` | `/usr/games/ttt` | `not found` | exec 失敗（2192B, executable 形式）|
| `wump` | `/usr/games/wump` | `not found` | exec 失敗（5184B, large file）|

#### 動作確認済みコマンド（同テストで確認）

| コマンド | 結果 |
|---------|------|
| `/bin/bas` | ✓ BASIC インタプリタ起動 |
| `/usr/games/bj` | ✓ BlackJack 正常動作 |
| `/usr/games/moo` | ✓ MOO（数当てゲーム）正常動作 |
| `/usr/games/cubic` | ✓ cubic 起動確認 |

`/bin/cdb` は「`a.out not found`」と報告することがあるが（a.out 不在時）、
a.out を用意して `cdb a.out` を実行すると `Trace/BPT trap -- Core dumped` でクラッシュする。
`db` と同じ ptrace/exec() バグが原因（→ [14-db-デバッガー-使い方.md §9](?doc=14-db-デバッガー-使い方.md)）。

#### 未解明点

- `dc` は magic 破損で確定。`bc`・`chess`・`ttt`・`wump` の失敗原因は未特定。
- `ttt`（0407 形式, 2192B）と `cubic`（0407 形式, 2468B）が同フォーマット・同サイズ帯で動作が分かれる。
- 仮説: 使用するシステムコールや命令セット（FPU 等）の差異か、特定アドレスへの依存の可能性。

詳細: [10-unix-v6-コマンドリファレンス §7](?doc=10-unix-v6-コマンドリファレンス.md)、[06-unix-v6-demo-commands.md](?doc=06-unix-v6-demo-commands.md)
